    Accounts

    Connect platforms

    Facebook, Instagram, Threads, LinkedIn, X, YouTube, TikTok and Reddit sign in through the platform itself. Open one, save the developer-app details you create on that platform, then press Connect. The setup steps for each are in docs/SETUP.md.

    Add by hand

    For Bluesky, Mastodon, manual reminders (such as the YouTube Community tab) and a test account.

    Quick start for places you post by hand:

    Image host

    Instagram, Threads and TikTok photos only accept an image from a public web address. The app uploads each image to your bucket for the moment it's needed, then deletes it. Any S3-compatible store works; Cloudflare R2's free tier is plenty.

    Claude

    Everyone uses their own Anthropic API key for Draft with Claude, so nobody's drafts are billed to someone else. Each person adds theirs by clicking the Claude button at the top of the page. The model and style guide below are shared.

    Team

    Only people listed here can sign in (with the Google account for that email). Check a new person against the WikiTree Team list first. Members schedule and edit posts; administrators also manage accounts, settings and this list.

    This changes the text shared by every channel that hasn't customised its own. Use a channel's own Edit button to change just that channel.

    Wiki table rows

    A row of the table on the social media posts page, ready to paste: the day, the subject, a link per platform (an empty cell where the post didn't go), and the YouTube and G2G cell. You can edit the text below before copying.

    Challenge post

    Say which stage of which WikiTree Challenge this post is for. It then goes in the Challenge's table instead of the everyday one.

    WikiTree Challenge table

    Channels down the side and the stages of the challenge across. A cell with a post that went out has its link; the rest are the usual blank links, ready for the post id. Mark posts as challenge posts when you schedule them, or with the "Challenge post" button in the Queue.

    The first cell of each row (picture, link and names)

    These change a little from one challenge to the next, for example the host's name. Saved for next time. The Reddit picture is a stand-in until you choose its file.
